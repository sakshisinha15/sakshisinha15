# 💫 About Me:
I am Sakshi Sinha, a passionate and dedicated B.Tech Computer Science Engineering student at Lovely Professional University with a strong interest in Data Science, Machine Learning, Backend Development, and AI-driven technologies. I enjoy building real-world projects and continuously learning new technologies to improve my technical and problem-solving skills. I have worked on projects such as an Obesity Level Prediction Model achieving 97.40% accuracy using Machine Learning algorithms, an AI impact analysis dashboard using Power BI, and a Spotify Data Analytics Dashboard for stream trend visualization. My technical skill set includes C++, Python, Java, JavaScript, Spring Boot, Scikit-learn, Power BI, MySQL, PostgreSQL, AWS, and core computer science fundamentals like DBMS, OOPs, OS, and Computer Networks. Along with technical development, I actively participate in hackathons, coding competitions, and open-source learning opportunities to enhance my practical exposure and collaborative abilities. I am highly motivated to contribute to impactful projects, explore innovative AI solutions, and grow as a software engineer in the tech industry.
